=====
Fixit
=====

Сервісний центр: облік ремонту техніки в Odoo 19.

Модуль веде замовлення на ремонт: клієнт здає пристрій, замовлення
призначають майстру, у замовленні є рядки робіт, а по замовленнях
друкується PDF-звіт.

Встановлення
------------

* Скопіюйте папку ``fixit`` у ``custom_addons``.
* Оновіть список застосунків і встановіть **Fixit**.
* Для тестових даних створіть базу з увімкненими демо-даними.

Запуск тестів::

    odoo -d test_db -i fixit --test-enable --stop-after-init

Карта роботи
------------

.. list-table::
   :header-rows: 1
   :widths: 25 35 40

   * - Вимога
     - Де
     - Що саме
   * - Процесна модель
     - ``models/order.py``
     - Замовлення на ремонт зі станами від «New Request» до «Picked Up» / «Cancelled».
   * - Дочірня модель
     - ``models/order_line.py``
     - Рядки робіт замовлення (One2many ``line_ids`` ↔ Many2one ``order_id``).
   * - Довідник
     - ``models/part.py``
     - Запчастини з ціною.
   * - Наслідування 1
     - ``models/client.py``
     - Клієнт сервісу — розширення ``res.partner``.
   * - Наслідування 2
     - ``models/repairman.py``
     - Майстер — розширення ``res.users``, призначається на замовлення.
   * - Представлення
     - ``views/*.xml``
     - List, form і kanban (групування за станом) для замовлень та форми довідників.
   * - Меню
     - ``views/menu.xml``
     - Кореневе меню «Fixit», видиме лише групі Fixit User.
   * - Візарди
     - ``wizard/``
     - Масове перепризначення майстра та вибір фільтрів для звіту.
   * - Звіт
     - ``report/order_report.xml``
     - PDF «Repair Order»: кожне замовлення на окремій сторінці з таблицею робіт.
   * - Демо-дані
     - ``demo/demo.xml``
     - 3 майстри, 3 клієнти, 4 запчастини, 8 замовлень і 9 рядків робіт.
   * - Тести
     - ``tests/test_fixit.py``
     - Перевірка прав доступу, правил ``ir.rule`` та обох візардів.
   * - Безпека
     - ``security/``
     - Групи User і Admin; User бачить лише замовлення, призначені йому.
   * - Документація
     - ``README.rst``, ``static/description/``
     - Цей файл, докстрінги та сторінка опису модуля з банером.

Права доступу
-------------

* **Fixit / User** — читає, створює й змінює свої замовлення, запчастини лише читає.
* **Fixit / Admin** — повний доступ до всіх записів і масове перепризначення майстра.
