Fixit

Service center: equipment repairs

Features

  • Repair orders with states from New Request to Picked Up.
  • Order lines with the works to be done.
  • Spare parts list with prices.
  • Kanban board grouped by order state.
  • Wizard to reassign many orders to one repairman.
  • PDF report "Repair Order" with filters by orders, repairmen and period.
  • Two access groups: a User sees only own orders, an Admin sees all.
